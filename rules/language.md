# Language

- Write all prose addressed to the user — explanations, summaries, findings, plans, questions — in the language the user is conversing in.
- Code, identifiers, code comments, commit messages, branch names, and PR titles/bodies follow the project's existing convention (usually English) unless the user asks otherwise.
- When delegating to a subagent, name the user's conversation language in the task prompt (e.g. "Report in Korean") so its report comes back in that language.
